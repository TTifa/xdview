## 本地资料边界

原始研究报告、现场接入记录和 APK 放在 docs/local/；旧 docs/guide/ 同样忽略。审查附件放在 docs/reviews/，研究中间产物放在 .analysis/。这些资料保留在本机，不随仓库发布，也不是构建或使用前提。

公开文档不能依赖本地资料才能读懂；将有价值的操作步骤和限制脱敏后写入对应专题。原始日志、签名地址、设备标识、账号、真实画面和录像不得复制到公开文档。

## 写作约定

- 以中文为主，协议字段、标识符、命令和路径保留原文。
- 区分观测、推断和未知；实测附日期、型号/固件、工具版本及复现方式，未知项明示。
- 历史结果不能当作当前验证；设备经验不推广为跨型号或跨版本保证。
- 命令使用明确的示例值，发布前检查链接、忽略规则及暂存内容。
- 新公开文档在本表登记，基础质量门禁仍只在 AGENTS.md 维护。
